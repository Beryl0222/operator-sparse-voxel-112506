# 稀疏扫描数据约定
每点有 scan_id、revision、point_id、整数体素坐标 xyz、feature、正置信度和可选接触标签。标签 0 表示无接触，1 表示接触，null 表示未标。相同坐标特征为置信度加权均值；标签只在所有非空标注一致时确定。坐标中的 batch_id 为身份的一部分。observed_boxes 是半开整数坐标盒的并集，代表已完成观测，盒内没点是已知零输入，盒外是未知；sealed_boxes 表示之后不会再补发同修订内容的范围。
卷积核 offset 为 [-1,0,1]^3。普通卷积 Y[o,p]=sum(W[offset,o,i]*X[i,stride*p+offset])，未活动但已观测坐标取零。submanifold 的输出坐标严格等于输入活动坐标；strided 层的活动坐标为存在活动输入满足核关系的 p；transpose 层使用同一关系的转置，输出限制在显式声明的目标观测坐标范围。padding 以整数 offset 定义，不再另作中心移动。资料层链为 submanifold(stride=1)、strided(stride=2)、transpose(stride=2)，含第一层到解码的同坐标相加跳接。相加仅对两侧均有有效覆盖的位置可交付。这里规定算子语义，不规定坐标索引或执行方式。
分类为输出两类 logits 的交叉熵，位置的标签来自对应原始体素的非冲突标注；监督分母为实际合格位置权重之和，空集合应报告无可提交目标，不返回伪零损失。扫描修订号定义观测和标签身份，旧窗口不得混入新修订。对坐标选择、覆盖和标签裁定不求导；特征聚合、卷积和跳接对有效输入及权重求导。
支持坐标绝对值<=2^20、输入活动体素<=32768、通道<=16、三层核。禁止按坐标范围分配稠密空间；坐标关系、临时特征与回传临时区合计最多 32 MiB，原始点、权重、最终各层公开输出和最终梯度不计入，缓存中间关系计入。float32 数值对照 atol=8e-5、rtol=8e-4；梯度 atol=3e-4、rtol=2e-3。小资料只给扫描与层参数，没有卷积关系表或训练结果。
